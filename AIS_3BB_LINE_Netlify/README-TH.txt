วิธีใช้งาน Netlify
1. แตกไฟล์ ZIP
2. อัปโหลดโฟลเดอร์ที่มี index.html ไปยัง Netlify ด้วยการลากวาง
3. ไม่ต้องใช้ build command หรือฐานข้อมูล

เว็บไซต์นี้เป็นหน้าเว็บที่สร้างใหม่โดยอ้างอิงแนวทางภาพจากหน้าหลัก ไม่ใช่สำเนาทุกหน้าของเว็บไซต์ต้นทาง
รูปภาพทั้งหมดที่ใช้จัดเก็บใน assets ไม่ใช้ hotlink
การสมัครทุกจุดไปยัง https://line.me/ti/p/okGbiHWs0U เท่านั้น
ไม่มีระบบล็อกอิน ไม่มีแบบฟอร์มเก็บข้อมูลหรือชำระเงิน
ภาพโปรโมชั่นเป็นภาพ ณ วันที่ดึงข้อมูล ต้องตรวจสอบเงื่อนไขล่าสุดก่อนรับสมัคร
ตรวจสอบสิทธิ์ใช้ภาพและเครื่องหมายการค้าก่อนเผยแพร่
แก้ข้อมูลได้จาก index.html และ style.css


อัปเดต 3 พฤศจิกายน 2569: เพิ่ม 6 หมวด 28 รายการ พร้อมราคา ความเร็ว อุปกรณ์ ระยะสัญญา และสรุปเงื่อนไข มีลิงก์ต้นทางสำหรับเงื่อนไขฉบับเต็ม สมัครผ่าน LINE เดิม ไม่มีล็อกอิน รายละเอียดใน package-data.json และแหล่งข้อมูลใน package-sources.json
แตก ZIP แล้วนำโฟลเดอร์ที่มี index.html อัปโหลดเข้า Netlify ได้โดยตรง ไม่ต้อง build
